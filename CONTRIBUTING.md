# Contributing

Please keep V1 focused on the deterministic Zhouyi experience. Run formatting, typecheck, unit/API tests, build, secret scan, dependency audit and relevant browser tests before proposing changes. Do not commit `.env`, tokens, private themes or production configuration. Use synthetic themes in tests and screenshots.

Rule changes must include independently reasoned expectations, not values generated by the function under test. Preserve bottom-to-top arrays and both algorithm/data versions. Keep the exhaustive 4096-case check. Text corrections need a precise source, edition, permission, before/after collation and a reproducible import adjustment; do not silently remove variants or invent citations. Keep the primary and alternate source provenance distinct.

Both Chinese and English core flow must remain usable, with keyboard and reduced-motion support. Model output must remain plain text under schema/citation validation. No fate predictions, personality/health inference, threats, professional decision advice, accounts or paid remedies.

Public push, production/Forge changes and credential configuration require the project owner's explicit authorization. Read the real deployment environment before preparing its route or controller changes. Report actual tests honestly; do not call a mock provider a real AI integration or a browser viewport a physical phone test.
